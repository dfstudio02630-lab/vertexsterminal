# Vertex Terminal

A responsive, dark market dashboard for monitoring forex, crypto, global indices, commodities, macro events, and selected company movers. The interface uses a dense, high-contrast financial terminal aesthetic with amber accents and compact market tables.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Data notes

The dashboard currently combines public market data when available with illustrative fallback/sample values. It is a monitoring UI prototype, not an execution or investment-advice platform. Public API availability, update frequency, and market-data licensing vary; values should be verified with a licensed provider before making decisions.
